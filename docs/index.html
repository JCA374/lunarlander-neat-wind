Evolving a network's weights and shape

NEAT (NeuroEvolution of Augmenting Topologies) starts from the simplest possible network and lets evolution add hidden nodes and connections only where they help. Here it learns to land Gymnasium's LunarLander. It uses no gradients and no backpropagation, just a population that improves every generation.

1The problem

The lander starts high above the surface with a random push. It has to touch down softly between the two flags. Gravity pulls it down, and every engine burn costs fuel.

The network gets 8 inputs……and scores 4 actions
x, y position · horizontal & vertical velocity · angle · angular velocity · left / right leg contact 0 do nothing · 1 fire left engine · 2 fire main engine · 3 fire right engine. The highest score fires.

The pilot is a neural network. Inputs on the left, actions on the right. Orange connections are positive and blue ones are negative; thicker means a larger weight. As the lander flies, the nodes light up with their values and the highest action score fires.

Nobody designed this network. It has no hidden nodes at all, just 17 of the 32 possible connections, and evolution found every one of them.

2A genome is a recipe for a network

Evolution works on a genome: a list of node genes (which neurons exist) and connection genes (from, to, weight, enabled). Reading the list builds the network.

Every connection gene carries an innovation number, a historical marker given out the first time that connection appears in the population. Genes with the same number in two genomes share an origin. neat-python names each gene by its (from, to) pair, which does the same job.

3Mutation grows the structure

  • Change a weight: the most common mutation (rate 0.8 per weight).
  • Add a connection: join two unconnected nodes (probability 0.5 per child).
  • Add a node: split a connection (probability 0.2). The old gene is switched off, the new incoming connection gets weight 1 and the outgoing one keeps the old weight, so behaviour barely changes.

Connections and nodes can also be deleted, so a network can shrink when parts of it aren't needed.

4Crossover: genes line up by history

Line two parents' genes up by innovation number. Matching genes are in both. Disjoint genes fill a gap in the other parent. Excess genes come after the other parent's last gene.

The child takes matching genes from either parent at random, and disjoint and excess genes from the fitter parent. However different the two networks look, the child is always a valid network.

5Speciation protects new ideas

A new node usually makes a network worse until its weights are tuned. Ranked against everyone, it would be thrown away too soon. So NEAT groups similar genomes into species and lets them compete mainly inside their own species.

δ = (c₁·D + c₂·Σ|Δw|) / N    # c₁ = 1.0, c₂ = 0.5
same species if δ < 2.2

D counts the genes that don't match, Σ|Δw| adds up the weight differences of the matching ones, and N is the size of the larger genome. neat-python works this out for connection genes and for node genes (biases) and adds the two. The 2002 paper uses the average weight difference instead; the idea is the same. Each species shares its offspring among its members. A species that doesn't improve for 20 generations dies out.

6One generation

Evaluate150 genomes each fly 5 episodes; fitness = average reward.
SpeciateGroup similar genomes by compatibility distance.
SelectInside each species the best 20% become parents; the 2 best survive unchanged.
ReproduceCrossover, then mutation, back to 150 genomes.
Every genome in a generation flies the same 5 starts, so the ranking is fair, and the starts change each generation. Because 5 episodes are noisy, each generation's champion also flies 100 episodes no genome ever trained on. "Solved" means at least 200 there.

7The run, generation by generation

313 generations × 150 genomes. Every genome of every generation is logged (data/population.csv.gz), along with whole populations every 10 generations, so the run can be replayed.

Every genome, every generation. Each dot is one genome, coloured by species. The green line is each generation's champion on 100 unseen episodes. It first passes 200 at generation 37, and the best champion (generation 164) lands 95% of unseen episodes.

Species over time. The classic NEAT plot: each band is a species and its height is its share of the population. 27 species appeared over the run. They split off, grew when they did well, and died out when they stagnated.

150 flights, one start. All genomes of a generation fly the same scenario, drawn as trails coloured by how they ended. Early on almost all of them crash; late in the run most land and the trails bundle into one strategy.

How the network changed. It starts fully connected: 32 connections, no hidden nodes. For about 160 generations evolution removed connections; the winner (generation 164) has no hidden nodes and 17 connections. Later the population grew to 15+ hidden nodes and 50+ connections, and those networks did worse on unseen episodes. Bigger is not automatically better, which is why NEAT starts minimal and why we select the winner on unseen episodes.

Champions over time. The same start, flown by the champions of different generations. Early champions crash or drift away; later ones slow down, straighten up and land.

8Reading the evolved network

Switch off one connection at a time and fly 40 unseen episodes. 9 of the 17 connections can go with almost no loss, and a few carry the whole skill:

  • vy → main (−12.8): falling fast drives the main engine: the brake. Without it: 0% landings.
  • angle → left (−7.2): tilt drives the left engine: stays upright. Without it: 5% landings.
  • R leg → right / none (−1.4 / +2.4): right leg down: stop firing, do nothing. Without it: 15% / 20% landings.
Where it still fails. On 1,000 more fresh flights the winner lands 96.8%. 16 of its 18 crashes end right of the pad, where it tips over on the slope. All 14 timeouts sit on the pad, 8 of them with only the left leg down: the leg sensor the network ignores, so it never settles. Every failure began with a hard sideways push. The full failure analysis is in experiments/.

9Run it yourself

# setup
git clone https://github.com/JCA374/lunarlander-neat-wind && cd lunarlander-neat-wind
python3 -m venv .venv && source .venv/bin/activate
pip install swig && pip install -r requirements.txt

# evolve (about an hour on 8 cores; every log is written as it goes)
python train.py

# watch it, test it, plot it
python demo.py runs/<run>
python evaluate.py runs/<run>
python visualize_all.py runs/<run>

# regenerate this page's videos from your own run (narration: see README)
python video_tools/make_explainer.py runs/<run>
